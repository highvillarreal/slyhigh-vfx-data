# SLYHIGH VFX Data Acquisition

Offline-first, shot-centric VFX data capture for production sets.

## v0.1

- Projects, shoot days, scenes, setups, shots and takes
- Camera + lens library
- Per-shot camera state
- Measurements with method + confidence provenance
- Reference photo/video capture
- Clean/background/foreground/practical plates
- Notes + voice notes
- Contextual acquisition checklist
- Printable tracking marker sheets with stable IDs + QR
- JSON, CSV and full ZIP exports
- Printable shot report / PDF workflow
- IndexedDB local persistence
- PWA + service worker for offline use
- Schema: `slyhigh.vfxdata` `0.1.0`

## Data safety

Production data remains on the device until exported. Export a full archive regularly during a shoot.
